# Установка на виртуальный сервер (Ubuntu 22.04)

Тестовое развёртывание: данные только тестовые. Docker-сборка в этой среде не проверялась, поэтому первый запуск возможно потребует правок: присылайте вывод `docker compose logs`.

## Перед началом
- Порты 80 и 443 открыты в файрволе хостера (и в `ufw`, если включён: `sudo ufw allow 80,443/tcp`).
- Есть имя хоста, указывающее на IP сервера. Без своего домена можно взять `85-202-193-13.sslip.io` (для IP 85.202.193.13 имя разрешается само). Свой домен лучше: у sslip.io общий лимит сертификатов.
- Пользователь `ubuntu` с `sudo`.
- Сервер 2 CPU / 2 ГБ RAM / 40 ГБ: для пилота хватает, но тесно. Скрипт сам создаёт swap 4 ГБ и собирает образы по одному (первая сборка 10-15 минут). Если памяти будет не хватать при работе, добавьте RAM до 4 ГБ: PDF (LibreOffice) самый «тяжёлый» компонент, поэтому по умолчанию документы делаются только в Word и Gotenberg не запускается.

## Шаги (на сервере, по SSH)
```bash
sudo apt-get update && sudo apt-get install -y git
git clone <адрес репозитория> hemcenter && cd hemcenter   # приватный репозиторий: через deploy key или загрузите архив
git checkout claude/festive-hopper-hoh3uc
scripts/deploy.sh 85-202-193-13.sslip.io you@example.kz
```
Скрипт ставит Docker (если нет), создаёт `infra/.env` со случайными секретами, пароль шифрования копий `infra/backup.pass`, собирает и запускает всё, генерирует ключи Web Push, создаёт администратора и ежедневную копию в 02:30. В конце он печатает одноразовый пароль администратора (логин `admin`): запишите его. Затем откройте `https://<имя хоста>`, войдите, смените пароль и настройте 2FA.

## Важно
- Скопируйте `infra/backup.pass` и `TOTP_KEY` из `infra/.env` в надёжное место. Они не хранятся в репозитории.
- Обновление: `git pull && scripts/deploy.sh <тот же хост>`. Секреты сохраняются.
- Остальное (резервные копии, восстановление, мониторинг): `docs/operations.md`.
- Постоянное боевое размещение: сервер в Казахстане (Закон №94-V, ст. 12).
